# سجل المراجعات الخارجية — wine-ai-adaptive

هذا الملف هو السجل الدائم للمراجعات الخارجية التي أُجريت على المشروع من جلسات
ذكاء اصطناعي خارجية (DeepSeek وQwen)، وما نتج عنها من قرارات هندسية، ومرجعةً
لكل توصية إلى مكان تنفيذها أو سبب عدم تنفيذها. الالتزام ذاته المعمول به في
`docs/AGENT_POLICY.md`: تصنيف بالأدلة، لا ادعاءات بلا تحقق.

---

## 1) جلسة DeepSeek — مراجعة التحصين الأمني (2026-11-10)

**المدخل:** محادثة مشاركة من DeepSeek تضمنت جرد تهديدات (16 بندًا) وتصاميم
تصحيح (9 بنود P1–P9) وخطوات تنفيذ لطبقة التخزين `KnowledgeStore`.

**المخرج المطبَّق:** هذه الجلسة هي المرجع المباشر لفرع
`security/harden-knowledge-store` (PR #2) ولجدول التهديدات في
`docs/THREAT_MODEL.md` (الترقيم النهائي T1–T14 بعد دمج البنود المتداخلة).

### مطابقة توصيات الجلسة مع التنفيذ

| توصية الجلسة | المكان في المشروع | التصنيف |
|---|---|---|
| رفض symlink في مسار قاعدة البيانات (P1/P2/P8) | `store.py`: `lstat` قبل الفتح + `O_NOFOLLOW \| O_EXCL` عند الإنشاء؛ اختبارات الرابط الصحيح والمعلّق | PROVEN |
| فحص نوع الملف ورفض غير الاعتيادي (P2) | `_verify_database_file`؛ اختبارات المجلد/FIFO/الجهاز | PROVEN |
| فرض أذونات المجلد `0700` وإصلاح القائم (P3) | `__init__` + `_verify_parent_directory`؛ `test_tightens_insecure_parent_directory_permissions` | PROVEN |
| فرض أذونات الملف `0600` وإعادتها عند كل فتح (P4) | `_create_database_file`, `_restrict_file_permissions` | PROVEN |
| تحقق عميق من المخطط لا `user_version` فقط (P5) | `_verify_schema`: بصمة SQL + `PRAGMA table_info`؛ رفض الأعمدة الزائدة/الناقصة/القيود المحذوفة | PROVEN |
| معالجة ملفات WAL/SHM/journal (P6) | `_verify_sidecar` + تنظيف الملفات القديمة؛ `test_wal_mode_database_remains_usable` | PROVEN |
| تهيئة ذرية ضد الحالات الجزئية (P7) | `BEGIN IMMEDIATE` واحدة + `test_rejects_partial_initialization` | PROVEN |
| فحص ملكية الملف والمجلد (P9) | مقارنة `st_uid` مع `geteuid` | PARTIALLY_PROVEN (لا يُختبر آليًا: يتطلب root) |
| صياغة صادقة لقيود TOCTOU | `docs/THREAT_MODEL.md` بند T11 بحالة PARTIALLY_PROVEN وقسم المخاطر المتبقية | مُوثَّق |
| نصيحة إلغاء التوكن المؤقت بعد الاستخدام | نُفِّذت كإجراء تشغيلي خارج المستودع؛ السياسة الدائمة في `docs/AGENT_POLICY.md` (البند 1) | مُوثَّق |

**نتيجة الجلسة:** كل بنود P1–P9 إما منفَّذة ومختبرة أو موثَّقة القيود صراحةً
(T5 وT11). لا بند متروك بلا قرار.

## 2) جلسة Qwen — تحليل الفجوات (2026-11-11)

**المدخل:** تقرير مراجعة خارجي قورن بندًا بندًا مع محتوى PR #4.

**النتيجة:** كل التوصيات الجوهرية كانت منفَّذة مسبقًا ومغطاة بالاختبارات
(التحقق من صلاحيات المجلد الأب، رفض symlink، سياسة الملفات الجانبية، التحقق
العميق من المخطط، رفض التهيئة الجزئية، الصياغة الصادقة لـ TOCTOU، قائمة
الاختبارات الأمنية المستقلة، SECURITY.md/Makefile/LICENSE/CLI/CI/أمثلة/تغليف).

**الفجوة الوحيدة:** استثناء مجلدات البيانات المحلية من `.gitignore` —
عولجت في commit `1a42852` («لا نرفع السجل الخام، بل الخلاصة المهيكلة»).

**تصحيح تحققي:** ملاحظة سابقة افترضت عطبًا في مشغّلات CI (قيمة `branches` في
`.github/workflows/ci.yml`)؛ التحقق النهائي أثبت سلامة المشغّلات تمامًا —
كان «وهم عرض» في قراءة مخرجات الطرفية لا عطبًا فعليًا. لا تغيير مطلوب.

**التفصيل الكامل:** ملحق جسم PR #4 بعنوان «تحليل فجوات جلسة Qwen الخارجية».

## 3) جلسة Qwen — تسليم البند أ: تصدير/استيراد مجهّل (2026-11-11)

**المدخل:** حزمة تسليم كاملة للبند (أ) من برومبت العمل
(`docs/reviews/qwen-work-prompt.md`): وحدة `wine_ai.portability` + ملفا
اختبار + توثيق + إضافات README/CHANGELOG، مع افتراضات معلنة عن واجهة
`KnowledgeStore`.

**التحقق قبل الالتزام (كله منفَّذ محليًا):**
- مطابقة الافتراضات المعلنة مع `src/wine_ai/knowledge/store.py`: صحيحة كلها
  (`SCHEMA_VERSION = 2`، `MAX_BATCH_SIZE = 100`، `_prepare_record`
  staticmethod، `add_records_atomic` ذرّية، `prefix_id` عمود اختياري).
- `pytest tests/`: **137 ناجحًا** (29 اختبارًا جديدًا في
  `test_portability_export.py` و`test_portability_import.py`).
- `python -m compileall src tests`: نظيف.
- فحص أسرار على الملفات الجديدة: نظيف.

**ما التُزم فعليًا:** `src/wine_ai/portability.py`، الاختباران،
`docs/portability.md`، قسم «تصدير/استيراد مجهّل» في README، وبند
Unreleased/Added في CHANGELOG (صياغته بالعربية توحيدًا مع بقية الملف).

**ما لم يُمس عمدًا:** طبقة التخزين والمخطط والترخيص؛ ربط CLI مؤجَّل عمدًا.

**التصنيف:** PROVEN (كود ملتزم ومختبر محليًا على 3.11/3.12/3.13 عبر CI).

## 4) جلسة Qwen — «حزمة v0.3»: مطبَّقة جزئيًا بتوجيه المالك (2026-11-11)

**المدخل:** حزمة شاملة تهدف إلى تحويل المستودع إلى «نواة تشخيصية v0.3»
مستلهمة تصاميم مشاريع مفتوحة المصدر، مع اعتمادية اختيارية مقترحة
(`ntstatus`) وأعمدة مخطط إضافية (`launcher`/`prefix_hash`). كُتبت الحزمة
بافتراض أن المستودع «KnowledgeStore فقط»، بينما المستودع الفعلي تجاوز
معظم مكوناتها.

**قرار المالك:** توجيه صريح بإضافة ما يفيد منها (بعد أن وُثّق سابقًا اعتراض
هندسي على الاعتمادية الخارجية). التصريف النهائي بندًا بندًا:

| بند الحزمة | القرار | السبب / الدليل |
|---|---|---|
| `docs/open-source-inspirations.md` (جدول الإلهامات وقاعدة «أنماط لا كود») | **مُضاف** | غير موجود سابقًا؛ أُعيدت كتابة المسارات لتطابق بنية المستودع الفعلية (`diagnostics/codes.py` لا `log_parser/codes.py`…) |
| سير «شخّص ← صنّف ← اقترح» (fix-it-in-wine/dllmgr) في CLI | **مُضاف** كأمر `wine-ai diagnose --log` للقراءة فقط | يطبع رموزًا مصنّفة وإصابات أنماط فقط — لا تخزين ولا قاعدة بيانات ولا نص خام في المخرجات (7 اختبارات جديدة في `test_cli.py`) |
| تحليل `vendorID` في `vulkaninfo --summary` (نمط protontricks/protontool) | **مُضاف** في `parse_vulkan_summary` | خريطة `0x8086/0x1002/0x10DE` فقط وما عداهما `unknown` — بلا تخمين؛ 5 اختبارات جديدة في `test_gpu_probe.py` |
| اعتمادية `ntstatus` الاختيارية (`decode` extra في pyproject) | **محجوز** | ينتهك «مكتبة Python القياسية فقط» في `docs/AGENT_POLICY.md`؛ الجداول الداخلية تغطي الرموز الشائعة. أي إدماج مستقبلي يتطلب تعديل السياسة بقرار صريح |
| أعمدة المخطط `launcher`/`prefix_hash` (استبدال `prefix_id`) | **محجوز** | كسر استقرار المخطط v2 والترحيل الذري و`portability` المبنية عليه دون مبرر كافٍ؛ الكشف عن المشغّل موجود في `environment/snapshot.py` والمخاطر موثقة في `THREAT_MODEL.md` |
| تجزئة البادئة `prefix_hash` (sha256 مقصوص) بدل الاسم المجرد | **محجوز** | نموذج خصوصية مختلف؛ الاسم المجرد (`prefix_name`) أبعد عن إمكانية الربط وموثق كقرار في `snapshot.py` |
| `ntstatus` import اختياري داخل `codes.py` | **محجوز** | كود ميت عمليًا (المكتبة غير مثبتة أبدًا) مع مرجع خارجي بلا إعلان اعتمادية — أنظف إبقاء الجداول الداخلية وحدها |
| استبدال شجرة الملفات كاملة (mission «apply file tree exactly») | **مرفوض** | سيطمس كودًا أحدث وأغنى (137+ اختبارًا) ويكسر الترحيل v1→v2 و`portability` و`THREAT_MODEL.md` |
| ملفات اختبار الحزمة (8 ملفات) | **مغطاة سلفًا** | 14 ملف اختبار قائم يغطي نفس المساحات وتزيد؛ أُضيف فقط ما يخص المُضاف حديثًا |
| `evidence.py`/`command.py`/`bridge.py`/`ollama/client.py`/`probe.py` الحالية | **مغطاة سلفًا** | المستودع يحوي نسخًا مكافئة أو أغنى (مثل: عميل Ollama المقيد بـ`127.0.0.1` بالبناء) |

**التحقق المحلي لهذا الدمج:**
- `pytest tests/`: **149 ناجحًا** (12 اختبارًا جديدًا: 7 CLI + 5 probe).
- `python -m compileall src tests`: نظيف. فحص أسرار: نظيف.
- سلوك `status` القائم لم يُمس؛ إضافات `probe_vulkan` متوافقة خلفيًا
  (مفاتيح جديدة في القاموس، المفاتيح القائمة بلا تغيير).
- نطاق التغيير: `cli.py` (أمر فرعي جديد) و`probe.py` (تحليل مُوسّع) وملفات
  توثيق واختبارات. لا مساس بطبقة التخزين أو المخطط أو الترخيص أو CI.

**التصنيف:** PROVEN للمنفَّذ (كود مختبر)، ومحجوزات موثقة بالأسباب فوق.
