# المكونات الخارجية (Third-Party Components)

هذا المشروع **لا يوزع ولا يضمّن** أي مكون خارجي في حزمته: كود التشغيل
بالمكتبة القياسية فقط، والحزمة MIT. الجدول أدناه يوثق البرامج الخارجية
التي **يتفاعل معها محليًا** (يكتشفها ويقرأ منها للقراءة فقط) وتراخيصها
المعلنة، تنفيذًا للقسمين 2.4 و6 من
[CROSSOVER_CLEAN_ROOM_SPEC.md](CROSSOVER_CLEAN_ROOM_SPEC.md)
والقسم 4 من [LEGAL_AND_LICENSE_BOUNDARY.md](LEGAL_AND_LICENSE_BOUNDARY.md).

## التفاعل المباشر (يكتشفه/يقرأه الكود)

| المكوّن | الترخيص المعلن | كيف يتفاعل معه هذا المشروع | حالة التحقق |
|---|---|---|---|
| **Wine** | LGPL-2.1-or-later | `wine --version` عبر قائمة سماح القراءة فقط (`command.py`)؛ واكتشاف بنية البادئات (`bottle_manager/discovery.py`) — قراءة أسماء ملفات وترويسات سجل، بلا تنفيذ ولا كتابة | موثق (ترخيص Wine معلن ومستقر) |
| **vulkaninfo** (من Mesa vulkan-tools) | MIT (مشروع Mesa) | `vulkaninfo --summary` عبر قائمة السماح؛ تحليل نصي بنيوي للخرج | موثق بتفاوت: ترخيص Mesa معلن؛ تُتحقق نسخة النظام عند الاستخدام الفعلي |
| **Ollama** (اختياري، محلي) | MIT | جرد فقط عبر REST على `127.0.0.1:11434` (`providers/ollama/client.py`) — لا prompts ولا إرسال بيانات | موثق (ملف LICENSE في مستودع ollama) |

## مكونات بيئة المستخدم (لا يلمسها الكود — ذكرٌ للسياق فقط)

تظهر في وثائق التصميم كأهداف مستقبلية ضمن حدود
[CROSSOVER_CLEAN_ROOM_SPEC.md](CROSSOVER_CLEAN_ROOM_SPEC.md)، ولا
يستدعيها أي كود حاليًا:

| المكوّن | الترخيص المعلن | ملاحظات |
|---|---|---|
| **DXVK** | zlib | ملفات المستخدم المثبتة محليًا فقط؛ الاكتشاف مستقبلي |
| **VKD3D-Proton** | LGPL-2.1-or-later | هدف مستقبلي في Graphics Backend Manager |
| **Winetricks** | LGPL-2.1 | لا يُستدعى؛ أي مستقبل يمر عبر طبقة موافقة |
| **Bottles** | GPL-3.0 | اكتشاف مشغّل من متغيرات بيئة فقط في `snapshot.py` (اسم مجرد، بلا مساس بالبرنامج) |
| **Lutris / Steam / Heroic** | تراخيص متباينة (بعضها مغلقة) | كشف من أسماء متغيرات البيئة فقط — لا استدعاء ولا تكامل |
| **CrossOver (CodeWeavers)** | برمجية احتكارية تجارية | **لا يُنسخ منها شيء إطلاقًا** (شيفرة أو CrossTies أو قواعد بيانات)؛ محوّل اختياري مستقبلي فقط وفق الجناح النظيف |
| **Proton (Valve)** | ترخيص مختلط بحسب المكوّنات | خارج النطاق الحالي؛ أي تعامل مستقبلي يتطلب مراجعة لكل مكوّن |

## قواعد التحديث

1. أي تفاعل جديد مع مكوّن خارجي يُضاف له صف هنا قبل دمج الكود.
2. أي تعارض ترخيص محتمل يوقف الدمج حتى قرار المالك (AGENT_POLICY).
3. التراخيص أعلاه موثقة كما تعلنها مشاريعها وقت الكتابة؛ عند أي توزيع
   أو تجميع مستقبلي تُعاد مراجعتها عند الإصدارات المعتمدة حينها.
4. المصادر: ملفات LICENSE في مستودعات المشاريع المذكورة وصفحات
   توثيقها الرسمية — لا يُعتمد على اقتباسات وسيطة.
