# الحدود القانونية والترخيص — wine-ai-adaptive

هذه الوثيقة تنفّذ القسم 2 من
[CROSSOVER_CLEAN_ROOM_SPEC.md](CROSSOVER_CLEAN_ROOM_SPEC.md)، وهي جزء من
عقد العمل: أي وحدة جديدة تُراجع مطابقتها لها قبل الدمج. الجدول المرجعي
للمكونات الخارجية وتراخيصها في
[THIRD_PARTY_COMPONENTS.md](THIRD_PARTY_COMPONENTS.md).

## 1) المسموح استخدامه

- توثيق Wine العام، وتوثيق CrossOver المنشور علنًا، وتوثيق Microsoft
  الخاص بمتطلبات التطبيقات.
- المشاريع مفتوحة المصدر ذات التراخيص المتوافقة — **بأنماط تصميم وسير
  عمل لا بنسخ شيفرة** (قاعدة «أنماط لا كود» في
  `docs/open-source-inspirations.md`).
- الاختبارات العملية المستقلة، والسلوكيات الوظيفية القابلة للملاحظة،
  وواجهات البرمجة العامة، والمعايير المفتوحة.

## 2) المحظور

- نسخ الشيفرة الاحتكارية لـCrossOver أو أي منتج تجاري مغلق.
- نسخ CrossTies أو إعادة توزيعها، أو استخراج قواعد بيانات CrossOver
  الخاصة، أو إعادة إنتاج وصفات تثبيت غير منشورة.
- استخدام ملفات تنفيذية أو مكتبات احتكارية دون ترخيص، أو تجاوز آليات
  الترخيص والتفعيل لأي برنامج.
- استخدام الهندسة العكسية لاستخراج أسرار تنفيذ احتكاري.
- نسخ كود من مشاريع مفتوحة المصدر بلا التزام ترخيصها — ما نأخذه منها
  تصميم ونمط عمل، وكل شيفرة هذا المستودع مكتوبة من الصفر فوق مكتبة
  Python القياسية فقط.

## 3) إجراء التطوير داخل الجناح النظيف

لكل وحدة: تحديد المتطلبات الوظيفية ← المصادر العامة المستخدمة ← تصميم
واجهة مستقلة ← تنفيذ مستقل ← اختبارات مستقلة ← توثيق مصدر كل مكوّن
خارجي ← مراجعة الترخيص ← تسجيل الأدلة. يُسجل ناتج كل خطوة في
`docs/reviews/EXTERNAL_REVIEWS.md` أو ملفات `docs/` المناسبة.

## 4) سياسة الترخيص

- هذا المشروع MIT (انظر [LICENSE](../LICENSE)). لا يجوز تغييره أو
  ادعاء ملكية عمل الآخرين (AGENT_POLICY).
- لا يُفترض أن تخضع كل مكتبات Wine أو DXVK أو غيرها للترخيص نفسه —
  كل مكوّن خارجي يُراجع على حدة (جدول THIRD_PARTY_COMPONENTS).
- المشروع **لا يوزع** أي مكون خارجي (Wine/DXVK/…): يتفاعل معه محليًا
  إن وُجد فقط. إذا أُضيف مستقبلًا أي توزيع أو تجميع، فكل تبعية تحتاج
  سجلًا كاملًا قبل ذلك: الاسم، الإصدار، الترخيص، مصدر الحصول، طريقة
  التوزيع، الالتزامات القانونية، ونتيجة المراجعة.
- أي اعتمادية Python جديدة — حتى الاختيارية — ممنوعة دون قرار مالك
  صريح مسجل (AGENT_POLICY: المكتبة القياسية فقط بلا استثناء).

## 5) خصوصية البيانات (جزء من الحد القانوني)

لا يُرفع أي بيانات مستخدم: قواعد بيانات محلية وملفاتها الجانبية،
ملفات `EXE/DLL`، محتويات Wine Prefix، سجلات شخصية، أو أي محتوى من
جهاز المستخدم خارج عينات مولدة اصطناعيًا صريحة. طبقة اكتشاف البادئات
تقرأ بنية المجلدات والترويسات محليًا فقط ولا تكتب ولا ترسل شيئًا.
