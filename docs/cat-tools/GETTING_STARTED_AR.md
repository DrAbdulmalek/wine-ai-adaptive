# البدء باستخدام Trados Studio وmemoQ على Linux

> **تنبيه توافق مهم:** هذا الدليل لا يَعِد بتشغيل أي من التطبيقين على Wine. وصفات المشروع الحالية لكليهما **UNPROVEN**، ولم تُسجّل نتيجة اختبار ميداني ناجح. الهدف هو إعداد مسار تشخيص منضبط، لا تثبيت التطبيقين تلقائيًا.

## ما الذي يفعله المشروع؟

يوفر `wine-ai-adaptive` أدوات Python محلية لفحص البيئة واكتشاف بادئات Wine وتحليل سجلات الأعطال. أوامر CLI الحالية للقراءة فقط؛ لا تنشئ بادئة Wine ولا تهيئها ولا تثبت Trados أو memoQ ولا تنفذ إصلاحات أو أوامر winetricks المقترحة.

## 1. فحص أولي آمن

على Manjaro/Arch يمكن جمع معلومات أساسية دون تغيير النظام:

```bash
uname -a
cat /etc/os-release
python3 --version
command -v wine || true
wine --version 2>/dev/null || true
command -v winetricks || true
command -v vulkaninfo || true
free -h
df -h "$HOME"
```

هذه أوامر استعلام. ملاحظة: استدعاء `wine --version` ينفّذ برنامج Wine نفسه، لذلك تجاوزه إذا كنت تريد فحصًا لا يشغّل أي برنامج خارجي.

## 2. تثبيت أداة التشخيص

تحتاج Python 3.11 أو أحدث. لا يحتاج تثبيت حزمة المشروع إلى صلاحيات root:

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/DrAbdulmalek/wine-ai-adaptive.git
cd wine-ai-adaptive
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

## 3. فحص الحالة واكتشاف البادئات

```bash
wine-ai status
wine-ai status --json
wine-ai prefixes
wine-ai prefixes --json
```

اكتشاف البادئات لا ينشئها ولا يعدّلها. تُعامل `~/.wine` كبادئة محمية؛ لا تستخدمها لتجارب CAT.

## 4. تنزيل التطبيقين

نزّل ملفات التثبيت فقط من حسابك أو قناة التنزيل الرسمية لدى البائع:
- Trados Studio: موقع وحساب RWS الرسمي.
- memoQ: موقع وحساب memoQ الرسمي.

تحقق من الإصدار ومتطلبات النظام والترخيص قبل التنزيل. لا تستخدم نسخًا معدّلة أو روابط مشاركة مجهولة. تنزيل الملف لا يعني أن تشغيله على Wine مدعوم.

## 5. عزل التجارب

استخدم بيئة اختبار مستقلة لكل تطبيق، ولا تخلط ملفات Trados مع memoQ. لا تستخدم `~/.wine` ولا بادئة عمل حقيقية. لا تنشئ أو تهيئ Prefix قبل مراجعة تعليمات الإصدار المحدد وخطة الاستعادة. واجهة Bottle Manager الحالية تنشئ مجلدًا فارغًا غير مهيأ فقط؛ هذا **ليس** Wine Prefix صالحًا ولا يعادل تشغيل `wineboot`.

## 6. عند حدوث عطل

اجمع سجل Wine محليًا، ثم شغّل:

```bash
wine-ai diagnose --log /path/to/wine.log --profile trados
wine-ai diagnose --log /path/to/wine.log --profile memoq
```

اختر ملفًا واحدًا وملف تعريف التطبيق المطابق. النتائج تلميحات فرز heuristic وليست إثباتًا للسبب الجذري. أوامر winetricks التي قد تظهر هي اقتراحات فقط ولا ينفذها البرنامج.

## حماية الخصوصية

- لا ترفع ملفات الترجمة أو ذاكرة الترجمة أو قواعد المصطلحات أو ملفات المشاريع أو بيانات الاعتماد.
- لا تشارك مفاتيح الترخيص أو رموز التفعيل أو بيانات الحساب.
- راجع سجل Wine قبل مشاركته؛ قد يحتوي أسماء مستخدمين ومسارات وأسماء ملفات أو بيانات خادم.
- لا ترسل سجلات أو ملفات طبية/مهنية أو محتوى سري إلى خدمات AI سحابية.
- احتفظ بالتشخيص محليًا، وشارك فقط مقتطفات منقحة عند الضرورة.

## حدود الإثبات

حالة وصفتي Trados وmemoQ في المستودع هي `UNPROVEN` و`last_tested: null`. لا ترفع الحالة إلى نجاح إلا بعد توثيق إصدار التطبيق وWine والتوزيعة والاعتماديات والاختبارات الوظيفية والترخيص والاتصال، وفق [مصفوفة الاختبار](TEST_MATRIX.md) و[سياسة الأدلة](EVIDENCE_POLICY.md).
